# Profiles

Copy a template, replace money/`REPLACE-ME` placeholders with real numbers, then run:

```bash
pia brief --profile profiles/nick.template.json
```

## nick.template.json

- **profile_id:** `nick-template`
- **Skills:** high `ai_ml`, `software`, and `content` (faceless / digital-friendly defaults)
- **Constraints:** `no_public_face: true`
- **Goals:** primary `cash_flow`, secondary includes `freedom`
- **Money fields:** all capital, surplus, debt, emergency fund, targets, and time budgets use the literal placeholder `REPLACE-ME` — fill these before analysis. The template is not valid Profile JSON until placeholders are replaced with numbers.

**Locale note (README only):** template locale is set to FL / US for Nick’s planning context; keep jurisdiction-specific tax/legal checks outside pia (educational planning only).
